Manuelle Installation

Wenn dein Browser den lokalen Netzwerkzugriff verhindert, installiere das Skript direkt in der AWTRIX-NG-Weboberfläche. Die Skriptdatei kommt direkt aus dem GitHub-Repository; die aktuelle Bedenkzeit wird in der heruntergeladenen Fassung voreingestellt.

Quellskripte: TC001.ax · TC002.ax
  1. Weboberfläche der AWTRIX-NG-Uhr öffnen und unter Scripts ein neues Skript mit dem Installationsnamen ChessTimer erstellen.
  2. Den kopierten Code einfügen oder die passende .ax-Datei importieren und speichern.
  3. Die Schachuhr am Gerät unter Scripts → ChessTimer starten. Die Bedenkzeit lässt sich über Apps → Chess Timer → Einstellungen ändern.
